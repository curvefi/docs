The Curve API at `api.curve.finance` returns Curve pools by registry and chain, with their gauges, APYs, TVL and volume. It also returns lending vaults, CRV and crvUSD supply figures and the list of chains Curve runs on. The reference below is generated from its OpenAPI file.
